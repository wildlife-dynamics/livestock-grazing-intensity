Shows how hard each grazing block is grazed and how long it rests between grazings, from EarthRanger livestock movement and cattle count events.

What it does

  1. Reads livestock movement events, cattle count events and grazing block features from EarthRanger.
  2. Splits each zone's movements into grazing periods: the blocks the herd moved to, from the date in to the next move.
  3. Works out each period's block area in hectares, its cattle count and how many days the blocks rested beforehand.
  4. Calculates stocking density, grazing intensity, the grazing to rest ratio and effective grazing intensity for every period.

Requirements

  • Access to an EarthRanger data source, set up as a connection.
  • A livestock movement event type, a cattle count event type, and a feature type for the grazing blocks. See the data the workflow needs.
