User Guide

How to load livestock-grazing-intensity, what data it needs, how to fill in its settings, and how to read the results.

1. Load the workflow

In the workflow runner, add a new template using this repository's URL, then select livestock-grazing-intensity from the templates list.

2. The data it needs

An EarthRanger data source, set up as a connection, with these three things:

DataWhat it must contain
Livestock movement eventsOne event each time a herd moves. The event details need a communityzone field and the blocks moved from and to. Fields named from, *_from, to, to_block or *_to are all merged, and each can hold one block name or a list of names.
Cattle count eventsA count of the cattle in a zone. The event details need communityzone and count fields. The run stops if either is missing.
Grazing block featuresOne polygon feature per grazing block. Feature names must match the block names used in the movement events. Capitals and spaces are ignored, so “Block A” matches “block a”. For the map, also include one polygon per grazing zone, named exactly like its communityzone value, including capitals.

4. Run it and read the results

The workflow writes its files to the results folder the runner gives it (ECOSCOPE_WORKFLOWS_RESULTS), and shows its dashboard when it finishes.

WidgetHow to read it
Stocking IntensityCattle-days per hectare, averaged over all grazing periods. The sparkline shows the monthly average. Higher means blocks carry more grazing pressure per visit.
Stocking DensityCattle per hectare while a block is being grazed.
Grazing to Rest RatioDays grazed for each day rested. Below 1 means blocks rest longer than they are grazed.
Grazing IntensityMonthly average cattle-days per hectare for each grazing zone, so zones can be compared over time.
Effective Grazing IntensityGrazing pressure spread over the whole graze-and-rest cycle: cattle per hectare, discounted by how long the blocks rested.
Livestock CountGrazing zones coloured by cattle count, in 5 classes, over the outlines of every feature fetched.

The CSV in the results folder has one row per grazing period, with every metric. The Technical Guide explains how each column is calculated.

Some values are blank by design. The latest period in each zone has no date out yet, so it has no duration or intensity. A block grazed for the first time within the time range has no recovery days.
